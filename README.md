# PharmaTrack
PharmaTrack| Build with AI: ABC (Anybody Can Code) Hackathon

Designed a role-based pharmacy inventory management platform featuring dual dashboards (Admin/Seller), multi-tier expiry tracking (color-coded by urgency and sorted by earliest expiry), and automated low-stock replenishment alerts prioritized by unit deficit.
Built a dual-phase operational verification engine where Sellers physically quarantine expired batches and log incoming deliveries, and Admins review and commit immutable changes across relational master, stock, and audit tables.
Contributed to both frontend and backend development
Technologies: React, TypeScript, Tailwind CSS, Express, Supabase (PostgreSQL), Context API, REST APIs
